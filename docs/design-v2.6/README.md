# DiskCurator 需求与设计基线 v2.6

**基线编号：DC-DESIGN-2.6。生效日期：2026-11-20。审查对应源码：DiskCurator Native 1.0.1。**

本基线将此前分散在 v2.2、v2.4、v2.5 中的有效决定合并为一套可独立阅读的规范。产品主线固定为：

**用户明确指定范围 → 完整扫描并记录 SHA-256 → 从多个视角观察结果 → 选择对象与操作 → 审阅计划 → 确认执行 → 查看历史与结果状态。**

扫描结果是唯一工作中心。左侧“智能整理、主题工具、基础工具”模式入口及“目录浏览”取消；基础、主题、智能仅表示同一工作区中的操作类别。操作类别不是重新扫描或切换库存的理由。

Native 1.0.3 的当前范围、后续工作和复跑入口见 [产品需求与验收矩阵](../../REQUIREMENTS.md)。本目录中标注 1.0.1 的状态和运行结论对应当时的源码。最新二进制的验证结果见 [发布验收记录](../../RELEASE-ACCEPTANCE.md)。

## 如何使用这套基线

**规范要求**表示产品必须满足的行为；**1.0.1 实现现状**表示源码审查能够确认的行为；**验证证据**表示实际执行的检查；**后续能力**表示尚未实现的设计工作。四者分别记录，不把未来方案写成已完成功能，也不把已有代码等同于 Windows 实机验收通过。

源码中的历史命名、测试名称和旧文档标题不改变本基线。遇到冲突，以 v2.6 的明确条款为准；旧文档保留为历史记录。当前功能与验收可以只阅读本目录，无需再拼接 v2.2/v2.4 的条款。

本次只修订设计文档。对应 C++、资源、构建脚本及测试代码没有变化；软件版本仍为 1.0.1。之前的 16/16 Linux 回归等记录是该源码的既有证据，并非本次文档修改后新增的一轮实机测试。

## 必须明确的当前边界

- 默认先选择要扫描的磁盘，初始选择为空；也可手动指定一个目录。不会自动扫描所有连接的磁盘。
- 主扫描完整读取可读普通文件并记录 SHA-256。当前有持久化索引，但每次主扫描仍完整重读；没有跨次增量跳过、中断续扫或可信的操作后增量刷新。
- 同哈希或同目录树指纹仅是候选；副本计数包含自身，计数范围和验证等级必须可辨认。路径份数不等同于独立文件对象数，更不等同于不同物理磁盘数。
- 副本保留数量 K=0～32、文件对象独立性和隔离执行前字节复核可配置。默认 K=2 不构成强制双副本规则。
- 跨磁盘结果可以共同观察；当前写操作限定一个扫描根，跨根融合和事务未实现。
- 文件操作不再触发隐式全盘重扫。旧结果标为过期；进一步分析与写操作前，用户明确选择范围重新扫描。
- 当前删除类动作是可恢复隔离，不提供永久删除，不立即释放空间。部分复制类操作不支持通用撤销。
- 原生 Windows GUI、CNG 运行和真实移动硬盘验收仍需单独完成；交叉编译、Linux 测试和内存微基准不能替代。

文档发布包包含所引用的既有验收与性能记录，供核查。代码与测试路径是源码导航，不表示文档包包含整个工程。

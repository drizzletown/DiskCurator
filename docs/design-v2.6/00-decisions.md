# 00 — 当前决定与变更基线

基线：DC-DESIGN-2.6；日期：2026-11-20；对应源码：Native 1.0.1。

## 1. 产品定位

DiskCurator 面向移动硬盘、历史备份和长期积累的文件目录整理。它先建立用户明确选定范围的内容库存，再帮助用户看清重复、差异、包含、冲突和组织结构，最后将用户决定转为可检查的操作计划。

技术路线保持 C++17、Win32 SDK / Common Controls、Windows 10/11 x64。GUI、CLI、主题分析和建议功能共享内容判定与事务能力，不建立多套含义不同的“重复”和“安全删除”规则。

## 2. 已确定的决策

| 决策 | 当前规则 | 对设计的约束 |
|---|---|---|
| D-01 工作中心 | 扫描结果是唯一工作中心 | 不再创建左侧三组模式入口或目录浏览树 |
| D-02 操作分类 | 基础、主题、智能是上下文操作类别 | 打开菜单不切换库存、不启动扫描、不清空选择 |
| D-03 范围选择 | 选择磁盘或指定目录；磁盘初始选择为空 | “默认磁盘模式”不等于“默认扫描全部磁盘” |
| D-04 完整哈希 | 主扫描对每一可读普通文件生成完整 SHA-256 | 不以抽样、大小或 mtime 替代初次内容读取 |
| D-05 首次结果 | 完整扫描后生成只读观察结果 | 不自动接续全范围字节核验、照片分析、融合推荐或结构推荐 |
| D-06 范围内分析 | 指定 A/B 的内容比较只涉及 A/B 子树 | 不因比较两个目录去读取第三个无关大目录；当前全根完整性前置条件另记为实现限制 |
| D-07 可见进度 | 阶段、文件、字节、时间、速度、路径、异常可见 | 总量未知时不能虚构百分比或全任务 ETA |
| D-08 用户策略 | K、文件对象独立性、隔离前字节复核由用户配置 | 不把默认两份或默认字节复核写成不可配置要求 |
| D-09 计划执行 | 修改前展示范围、路径、策略和冲突，并冻结计划 | 新预览失败不能继续误用旧计划；修改策略须重新生成要应用新策略的计划 |
| D-10 操作后状态 | 文件操作使当前快照过期，不隐式重扫 | 只读查看与历史保留；继续分析和整理前显式扫描 |
| D-11 能力边界 | 观察可跨磁盘；当前修改限单根 | 候选副本数不能直接当作本根执行时的合格保留者数量 |
| D-12 证据表达 | 实现、测试、实机验收和后续设计分别标注 | 不用微基准推算 1TB 实盘承诺，不用编译通过代替 GUI 运行通过 |

## 3. 旧版条款如何收敛

| 旧表述或分散规则 | v2.6 中的处理 |
|---|---|
| L1/L2/L3 三套工作模式、默认智能向导 | 取消导航含义，合并为同一结果工作区的操作类别 |
| 左侧原目录树、目标目录树为主导航 | 取消；目录通过目录观察、A/B 选择、映射和计划视角表达 |
| 默认全盘扫描、自动发现全部磁盘并扫描 | 改为用户先明确选择磁盘；默认模式只决定输入方式 |
| 扫描后自动进入全范围精确比较和智能建议 | 改为完整哈希＋观察；后续重任务由用户明确发起 |
| 必须始终保留两份／必须始终二次字节复核 | 改为可配置保留策略，区分默认值、用户选择与执行保证 |
| 哈希候选只能显示，不能生成隔离预览 | 允许基于本次完整哈希生成候选计划；执行按冻结策略核验，不把候选升级成精确观察结论 |
| 选择两目录前先核验整个根的全部内容 | 内容读取限制在 A/B 子树；1.0.1 的全根完整性门槛不等于全根内容读取 |
| 文件操作后自动重扫根目录 | 改为结果过期和显式重扫；可信增量刷新列为后续能力 |
| 元数据完成就已经有可操作的最终扫描结果 | 首次完整哈希完成后发布正式观察结果；枚举阶段仅有进度，不声称已实现渐进式可操作库存 |
| 缓存存在就等于增量扫描、断点续扫已完成 | 明确拆开：已实现索引保存，未实现可信跨次跳过和中断续扫 |
| 强制性性能门槛直接引用某次小文件 CTest 耗时 | 使用分阶段、固定数据集和记录设备条件的性能验收；本轮微基准只证明其测量范围 |

v2.1～v2.5 各版保留用于追溯。当前条款已全部纳入本基线，不再要求“旧版继续有效的部分由读者自行拼接”。

## 4. 术语

| 术语 | 含义 |
|---|---|
| 扫描范围 | 用户选择的磁盘集合，或一个手动根目录 |
| 当前操作根 | 当前允许计划与执行的单一根目录 |
| 库存／快照 | 某次扫描发现的路径、大小、时间、哈希与异常记录；不是文件系统实时镜像 |
| 观察视角 | 对同一库存的文件、目录、副本、关系、问题、映射等呈现 |
| 同哈希候选 | 大小与完整 SHA-256 相同的文件路径集合，包含自身 |
| 已精确核验 | 在相应任务范围内实际比较内容所得到的结论，不是永久不变的事实 |
| 独立文件对象 | 不将同一文件对象的硬链接重复计为独立副本；并不代表跨物理设备 |
| 过期结果 | 已知文件操作可能改变了快照，仍可参考但不能继续驱动新的分析或修改 |
| 隔离 | 将符合当前计划与策略的文件移入可恢复工作区；不会立即释放磁盘空间 |
| 融合 | 在指定目标中补充源的独有内容并保留冲突版本，不删源、不覆盖已有异内容 |
| 目录重组映射 | 从原路径到拟建新结构的映射，允许编辑与拒绝，先预览后复制构建 |

## 5. 后续变更规则

修改产品行为时，同时更新对应需求、交互状态、实施状态和验收项。新增索引字段或缓存格式须说明版本与失效条件；新增跨根写入、永久删除、后台扫描或自动执行均需单独设计，不能以性能优化名义静默引入。

只更新文档不改变运行行为。本轮发现的源码限制在 [07-implementation-status.md](07-implementation-status.md) 中列出，留给后续实现与验收。

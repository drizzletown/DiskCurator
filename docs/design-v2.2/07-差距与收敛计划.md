# 07 差距审计与下一轮工程工作

## 已编码但尚未 Windows 实测

- `scan_hashed`：所有普通文件的完整 SHA256、路径/大小/mtime 的本地 TSV 索引、失败状态和取消。
- 完整哈希候选分桶；疑似重复仍需 `equal_bytes` 确认事实。
- 0..32 的用户选定活动保留数、物理独立性判断开关、完整字节复核 / 扫描哈希快速模式、零份授权。
- CLI `hashes`、`--keep`、`--count-hardlinks`、`--trust-scan-hash`、`--allow-zero`；Win32 操作前策略对话框及普通选项持久化。
- 可移植核心测试与严格警告测试通过；Windows GUI 与 Windows CLI 策略验收仍待执行。

## 尚未开发

- 哈希索引增量读取、跨启动热缓存、File ID/Volume ID 严格失效规则、SQLite 索引、增量目录刷新。
- 在 GUI 文件明细直接查看完整 64 字符 SHA256 的专用信息面板；当前完整值可通过 CLI/缓存查看。
- 普通文件删除、永久清空隔离区、实物磁盘容量回收，需要另立高风险任务设计/审批机制。
- 整理后对跨物理硬盘副本的验证和灾难恢复保证（当前项目边界之外）。
- 原有基础层仍缺持久文件保护标记、通用文件复制/移动和全部融合策略的完整图形化验收。

## 下一阶段优先级

1. **Windows MSVC/CTest 9/9** + 配置界面 + CLI 真实临时目录与中文/硬链接测试。
2. **性能回归**：准确计时完整 SHA256 首次扫描；必要时优化缓冲、存储调度和增量索引，但不能在用户选择强复核时偷偷降低保障等级。
3. **安全/恢复**：K=0 与快速模式的风险确认、故障注入、缓存损坏不影响用户资料。
4. **L1 收尾**：文件对象保护、普通管理命令、目录策略融合和 GUI 易用性，直到质量门槛通过再进入正式版。

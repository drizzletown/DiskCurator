# DiskCurator 需求与总体设计基线 v2.2

**日期**：2026-11-18；**实现参照**：DiskCurator Native v1.0-rc9 源码候选。

## 版本决策

本版替代 v2.1 的两项强制设计：

1. **选择根目录后先全量扫描，逐个计算普通文件的 SHA-256，记录路径、大小、mtime 和 SHA-256。** 文件内容哈希是持久索引的数据，而非仅对重复候选计算；扫描完成或失败的情况必须显式披露。缓存位于用户本机应用目录，**不写进待整理目录**。
2. **清退安全策略由用户决定，不再把“两份独立副本、逐字节复核”作为不可修改的固定数值。** 推荐默认值为保留两份、不同文件对象、执行前逐字节复核；可选择保留 0～32 份、是否将硬链接路径计为独立路径，以及可信度不同的验证方式。危险选项需要明确单独确认。

全文继续沿用：**L1 独立手工基础工具 → L2 主题组合 → L3 智能整理**；所有写入统一由 `Plan` 和事务执行器处理，融合仅复制、不覆盖，旧目录清退独立授权。**软件目前仍不实现永久删除**，只提供可审计的隔离；本设计给未来删除流程定义约束，但不将其写成已实现。

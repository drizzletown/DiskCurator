# 01 软件需求规格说明书（SRS）

## L1 基础能力

| ID | 要求 | 验收条件 |
|---|---|---|
| FR-101 | 扫描指定根目录所有普通文件及目录；统计大小、日期、类型和异常 | 目录/文件清单完整，reparse point 不被跟随，错误可见 |
| FR-102 | 主扫描对每一可读普通文件计算并保存 SHA-256 | 空文件、大文件、中文路径、同名不同内容均有稳定结果；失败项显式状态 |
| FR-103 | 精确重复文件人工管理 | 用户自由选定隔离成员，按当前策略生成计划，不出现未批准的文件 |
| FR-104 | 完全相同目录人工管理 | 考虑文件名/层级/空目录/字节内容；可按旧目录范围提出隔离计划 |
| FR-105 | 相似目录自动发现 | 内容重合、包含、不同相对路径、空目录差异有可解释数值与截断标记 |
| FR-106 | 任意指定两个目录评估与融合 | 无自动阈值限制；看见冲突、独有文件、目标映射；复制而不覆盖 |
| FR-107 | 批量改名、分类归档、搜索过滤、排序、CSV 结果 | 操作前预览，冲突拒绝，不更改未选中的文件 |
| FR-108 | 用户配置清退保留策略 | 0～32 份、独立对象判断、是否二次字节复核；危险项有独立确认 |
| FR-109 | 旧目录定向清退仅选择符合当前策略的项 | 保留者在整个指定旧目录外；其余文件给出阻断原因 |
| FR-110 | 操作日志、撤销、恢复、故障诊断 | 被操作路径可追溯；日志损坏、异常临时对象拒绝盲目操作 |

## L2 / L3 任务

| ID | 要求 | 验收条件 |
|---|---|---|
| FR-201 | 历史备份融合与主题整理 | 复用 L1 比较、差异分析、复制及计划接口；不独立发明另一套文件等价规则 |
| FR-202 | 智能生成建议结构 | 按类型、真实内容重合和原有主题生成目标树，保留无法判定项 |
| FR-203 | 用户编辑来源→目标关系 | 编辑后重新计算计划，确保完整映射、冲突另存、可拒绝建议 |
| FR-204 | 两阶段迁移 | A 复制并验证新结构；B 另行确认清退，严禁默认连带删除 |

## 内容与策略规则

| ID | 规则 |
|---|---|
| BR-01 | SHA-256 是内容索引而非数学上零碰撞的绝对证明；“完全相同”组须逐字节核对 |
| BR-02 | 完整扫描失败者不能被无条件纳入精确一致性结论；只对已证实的对象显示对应内容 |
| BR-03 | 每个隔离计划冻结 `RetentionPolicy`，保留数为用户配置的 K，不再强制常量 2 |
| BR-04 | K≥1：每个被隔离内容至少留下 K 个活动路径；如用户要求不同文件对象，路径不能互为硬链接 |
| BR-05 | K=0：仅在用户明确启用零保留风险选项并再次确认后允许；当前仅可恢复隔离，不永久删除 |
| BR-06 | 默认字节复核；用户可选降低保证级别的 SHA256+文件状态快速模式，此时不能宣称提交前逐字节重验 |
| BR-07 | 旧目录定向清退要求保留者位于整个旧目录范围之外；被同次计划隔离的项不计入保留者 |
| BR-08 | 目标已有异内容文件不覆盖；变化的扫描、异常路径、事务损坏须拒绝或显式记录 |
| BR-09 | 复制/迁移与目录清退分离；隔离区不计入活动文件且不释放磁盘空间 |
| BR-10 | 保留的活动路径不能被当前计划同时选为清退源；策略只能通过重新审批生效 |

## 非功能与体验需求

| ID | 要求 |
|---|---|
| NFR-01 | Windows 10/11 x64，MSVC C++17，纯 Win32 SDK；基础层与主题/智能层共享执行器 |
| NFR-02 | 首次扫描包含全量内容读取，UI 必须显示文件/字节进度、允许取消、不阻塞主窗口 |
| NFR-03 | 哈希索引只写用户应用缓存位置，可清理可重建，不创建在被扫描数据根目录 |
| NFR-04 | 每项性能测量分开报告枚举、哈希、字节核验、目录分析、计划生成和实际复制 |
| NFR-05 | 提供真实 Windows/NTFS/USB 和中文路径测试证据，不用 Linux 核心测试冒充 GUI 验收 |
| NFR-06 | 配置及风险摘要出现在执行前计划；快速模式/零份模式不可由隐式默认启用 |

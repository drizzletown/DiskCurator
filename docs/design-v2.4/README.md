## 不变的产品主线

选择磁盘/文件夹 → 用户确认启动一次完整 SHA-256 扫描 → 基于相同的索引切换观察视角 → 选中证据与具体文件/目录 → 产生操作预览 → 用户确认 → 执行验证及历史审计。

默认不能跨卷修改。选中卷后进入已存在的单根精确核验和事务执行器，清理的活动副本数及复核等级遵守用户已配置策略。任何字节比较不应被单纯 SHA-256 匹配替代。

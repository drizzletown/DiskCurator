# 01. 需求与任务流程

## 用户问题

用户持有多年移动硬盘和多次复制的相机/资料备份，想先知道数据全貌，再决定哪些文件重复、哪些目录相似、如何安全融合，以及如何调整整理后的目录结构。用户不应被迫先学习十多个独立算法按钮。

## 1. 扫描范围必须由用户决定

- SCOPE-01：默认呈现“选择磁盘扫描”和“指定目录扫描”两种方式，**默认模式不等于默认选中所有磁盘，也不自动读取任何文件**。
- SCOPE-02：选择磁盘模式支持在 C:、D:、F: 等卷中勾选 1..N 个盘符，仅将选中范围传给扫描任务；未勾选的盘符绝不枚举其子目录或读取文件内容。
- SCOPE-03：选择器显示盘符、卷标、容量和空闲空间，允许 Windows 报告的介质类型提示，不凭盘符推断是否为移动硬盘。可用卷列表不包含网络卷和光学介质。
- SCOPE-04：冻结所选卷的卷 GUID（可获得时）、序列号和类型，扫描前与扫描后复核；卷被拔出或盘符改指其他卷时使结果失效。此检查不能取代对单次文件写入或硬件故障的保护。
- SCOPE-05：指定目录模式只扫描指定树，允许系统盘上的某个数据目录，不需要先对整个 C: 盘哈希。
- SCOPE-06：扫描包括所有可读普通文件的完整 SHA-256，结果写入可重建缓存。不可读、变更文件和失联卷必须明确报告，不伪称完整。

## 2. 扫描之后，先观察再行动

| 视角 | 显示的关键信息 | 直接可做的事 |
|---|---|---|
| 磁盘概览 | 选定卷、容量、文件数、完整度、哈希候选组数 | 进入其中一个卷的受控管理 |
| 文件视角 | 文件名、路径、类型、容量、SHA-256 状态、候选副本数 | 打开位置；选卷核验后人工选择隔离成员 |
| 目录视角 | 完整路径、累计大小、文件数、相同内部目录树候选数 | 查看目录；选卷后比较任意两目录、融合、清退 |
| 哈希副本组 | 同大小同 SHA-256 文件组、每个具体文件位置、潜在占用 | 查看成员，选卷后进入精确核验/人工处理 |
| 目录关系 | 完全相同、内容重叠、包含、同名异内容、独有文件 | 指定两目录评估、策略融合 |
| 照片视角 | 相似图片候选、EXIF 与日期分类 | 人工确认相似，分类归档 |
| 空间视角 | 最大文件、最大目录、类型占用 | 选择整理范围或导出报告 |
| 问题与风险 | 读取异常、缺哈希、卷变化、不完整结论、清退阻断 | 修复问题、重新扫描、查看日志 |
| 目标结构 | 原始树与目标树及文件映射 | 拒绝/编辑映射/预览迁移 |
| 操作历史 | 已执行事务、隔离、撤销、故障恢复 | 审计、按允许的策略恢复 |

前四项与问题视角属于 v1.0-rc11 选中多磁盘后的新增主要显示；原有单根目录的专业视角和操作继续复用。计划中的跨卷精确验证和跨卷受控迁移尚未实现。

## 3. 统一上下文操作

鼠标选中某条记录 → 右键菜单只显示当前视角可用的操作。例如文件重复项提供“人工隔离所选”；目录对提供“比较/融合预览”；目标结构映射提供“修改映射”；执行预览提供“审查并确认”。

操作分为三层：

1. **证据（只读）**：扫描、哈希候选、字节核验、目录比较、相似候选。
2. **计划（不修改）**：选择对象、指定方向和策略、确认目标路径、审查副本影响。
3. **受控执行**：执行器重新校验其策略要求，不覆盖用户已有文件，记录事务、异常和恢复状态。

### 用户可配置安全策略

最少保留活动副本 0..32、是否区分不同文件对象、是否执行前逐字节复核由用户选择。高风险设置仍需要明确确认。隔离不是永久删除，不能释放容量，也不能让软件宣称具备跨硬盘容灾保证。

## 4. 面向移动硬盘的典型流程

勾选 E: 和 F: → 点击扫描（只读全量哈希） → 切换“文件视角”搜索 `IMG_` → 查看同哈希候选出现在哪个卷 → 切换“目录视角”发现相机备份的累计大小与相同树候选 → 进入 E: 精确复核具体目录 → 指定来源/目标并评估相似性 → 生成融合计划 → 查看冲突和新旧目录映射 → 确认非破坏性复制 → 复核结果 → 如需清理旧副本，单独应用用户选择的隔离策略。

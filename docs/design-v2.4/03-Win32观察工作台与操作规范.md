# 03. Win32 观察工作台交互规范

## 首屏（执行扫描前）

```text
┌────────────────── DiskCurator ──────────────────────────────────────────┐
│  扫描范围  [选择磁盘扫描 ▾]  [未选择磁盘] [选择磁盘…] [开始扫描] [停止] │
├───────────────┬────────────────────────────────────────────────────────┤
│ 智能整理      │ 选择要整理的磁盘                                  │
│ 主题工具      │ 盘符 / 卷标 / 容量 / 剩余空间 / 介质类型提示             │
│ 基础工具      │ □ C: [系统盘可能扫描不完整]                           │
│               │ ☑ E: 影像备份                                       │
│               │ ☑ F: 旧资料（只是示意，不作真实默认勾选）             │
│               │ 只扫描勾选卷；开始前和结束后复核身份                  │
└───────────────┴────────────────────────────────────────────────────────┘
```

用户点击“选择磁盘”才出现选择窗口，默认没有磁盘被勾选；按下“扫描所选磁盘”才读取。切换“指定目录扫描”后，输入框与浏览按钮作用于文件夹而不是磁盘选择。

## 扫描后主界面

```text
┌────────────────── DiskCurator ──────────────────────────────────────────┐
│  扫描范围/结果概览  已扫描 E:,F:   完成/部分完成 · N 文件              │
├───────────────┬────────────────────────────────────────────────────────┤
│ 智能整理      │ [观察视角 ▼] [按名称/路径筛选───────────────────────] │
│ 主题工具      │ 记录名          位置        容量     候选副本 / 状态  │
│ 基础工具      │ IMG_1001.jpg    E:\DCIM    8MB       3 份候选         │
│               │ IMG_1002.jpg    F:\旧数据  6MB       1 份候选         │
│               │ ...                                                │
│               │ 右键：查看位置 / 进入该卷进行精确核验              │
└───────────────┴────────────────────────────────────────────────────────┘
```

观察视角默认给“磁盘概览”，可以切换为文件、目录、哈希副本组和扫描问题；进入一个卷后还可切换重复文件、重复目录、目录关系、照片、备份安全、目录比较、映射、操作历史等已有详细视图。

## 上下文操作要求

- 每条可操作记录具有稳定的根卷和相对路径身份，切换排序或筛选不能错把行号当作文件身份。
- 对文件视角：选中具体成员后可以在单根精确重复结果中预选相同文件并申请隔离；多个选择必须遵守用户确认的副本保留策略。
- 对目录视角：可以选择两条记录进行指定目录比较；生成融合预览必须单独确认来源和目标方向；目标存在同名不同内容时保留版本。
- 对目录映射：允许在计划里编辑目标结构，所有源内容都应有可追踪去向。
- 对操作预览：实际执行必须经过二次确认及文件重新核验。
- 对多卷概览：只提供查看路径和选择单卷进入精确管理，**不出现跨卷删除或融合执行按钮**。

## 界面质量原则

默认不堆积十几个按钮；清晰区分“候选”与“已验证”，UI 直达用户目标；有异常项要让用户能找到，进度可取消，真正写入时防止窗口被误关。行数过多应显示精确已显示/总量及搜索范围。低风险操作支持撤销，风险策略单独说明。

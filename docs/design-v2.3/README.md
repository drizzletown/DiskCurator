# DiskCurator 需求与总体设计基线 v2.3 — 双扫描范围

**日期：2026-11-19**；**实现参照：v1.0-rc10 源码候选**。本版覆盖 v2.2 的「扫描范围仅限指定根目录」约束；文件内容验证策略、三层交互、人工基础工具及事务执行规范仍按 v2.2 执行，除非与本版冲突。

## 冻结决策

- 启动时**默认选择「全盘扫描」**，但不未经用户动作就启动可能耗时很长的磁盘全量读取；点击「开始扫描」后才执行。
- **全盘**定义为 Windows 当前所有**可访问的本地固定磁盘及已连接可移动磁盘的逻辑卷**。不默认扫描网络盘、光盘/无介质设备；扫描失败的卷明确列出。全盘不等同硬件所有扇区或不受权限限制的取证。
- **指定目录**由用户手动选择一个根目录，只扫描该目录及其下普通目录；兼容 v2.2 的全部整理工作流。
- 两种模式都读取全部可读取普通文件、计算完整 **SHA-256**，并保存本机缓存索引。哈希相同仅代表内容重复候选；「字节级相同」结论须经后续内容核对。
- 全盘分析对用户资料是**只读跨卷盘点**；会在本机应用数据目录写入可重建 SHA-256 缓存，不创建资料事务目录。用户必须先明确选择一个卷，才能进入原有的单根目录管理工作流；任何跨卷复制、删除、融合不因新增全盘模式而自动开放。
- 不可读取项、符号链接/目录 junction、扫描不完整状态必须显式披露；不能把部分扫描称为“全部已扫描”。

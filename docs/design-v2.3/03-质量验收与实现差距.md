## 正式发布阻断项

- Windows MSVC Win32 GUI 编译与启动成功；10/10 CTest；CLI 与 GUI 冒烟测试全部通过。
- 本机有多个逻辑卷时，能够正确列出卷，核对路径与计数、异常报告；在不可访问系统文件上明确显示「部分完成」。
- 断开外置 USB 盘期间的读取错误能够导致该卷扫描不完整，绝不能产生清退建议。
- 用户选择单卷或手工目录后，继续验证已有隔离计划的用户保留策略，双副本计数及目标文件实际内容。
- 全盘/手工扫描都不能意外创建 `.DiskCurator-System`，不可在只读分析阶段更改资料文件。

**质量状态**：当前为源码候选，不能把 Linux 10/10 回归当作 Windows 全盘性能与安全验收的替代。

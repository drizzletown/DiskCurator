# 双扫描模式：软件需求规格（SCAN-SCOPE）

## 范围选择

| 编号 | 要求 | 可观察验收 |
|---|---|---|
| SCOPE-01 | 运行后默认选中「全盘扫描」 | Win32 下拉框默认序号 0 |
| SCOPE-02 | 用户可选择「指定目录扫描」 | 下拉框序号 1，目录框和浏览可用 |
| SCOPE-03 | 切换范围废弃所有旧的操作预览，不触发写入 | 旧执行计划无法继续执行 |
| SCOPE-04 | 选择「全盘扫描」时，点击扫描自动发现本地固定卷与可移动卷 | 盘符列表与本机 Windows 逻辑卷对应 |
| SCOPE-05 | 自动跳过网络/光学/未就绪卷并展示异常信息 | 无介质/无权限时不崩溃、不误报完整 |
| SCOPE-06 | 两种模式中，对可读取普通文件逐个计算 SHA-256 | 每个成功读取文件具有 64 位小写十六进制哈希 |
| SCOPE-07 | 全盘概览显示每卷文件数、容量、扫描完整度和同哈希候选 | 能从候选查到涉及的卷与文件路径 |
| SCOPE-08 | 全盘候选仅标记「待逐字节确认」 | 禁止把 SHA 匹配直接作为清退证明 |
| SCOPE-09 | 用户选择一卷后，复用内存中的 SHA 清单，不立即全盘重读 | 单卷后续整理调用现有精确验证和计划执行器 |
| SCOPE-10 | 执行复制/隔离/重命名必须明确选定单一根目录 | 全盘概览不能直接产生修改全盘的计划 |
| SCOPE-11 | 扫描提供逐盘及逐文件进度、可取消 | 停止任务后不得产生混合的新旧扫描结论 |
| SCOPE-12 | 外置设备断连时保留可诊断的错误信息 | 不将设备不在线误判为内容不存在 |

## 任务流程

1. 启动后界面默认「全盘扫描」。点击开始后枚举 Windows 当前可访问本地逻辑卷（含 USB 移动硬盘）。
2. 后台逐卷盘点并计算 SHA-256，保存为各卷独立的 `Inventory`；同时形成跨卷哈希候选。界面显示实际文件数、容量与错误数。
3. 用户浏览「全盘概览」，双击一个卷，切换成以该卷为根的精细管理视图；原始哈希结果复用，但精确重复关系仍需字节验证。
4. 用户也可以从开始选择「指定目录扫描」，浏览到照片备份文件夹，直接进入原来的单目录功能。
5. 管理操作始终由用户确认，遵守其副本保留数量与核验等级策略；全盘扫描本身不会创建 `.DiskCurator-System` 事务目录，不会移动或删除用户资料文件；SHA-256 索引会写入本机应用缓存目录。

## 不在本阶段的范围

- 并行跨卷事务、跨卷主动融合、跨盘全局隔离或删除。
- 从物理扇区、已删除文件或无权限的目录取证。
- 对网络共享、远程 NAS 的自动批量扫描。
- 利用索引跳过下一次 SHA-256 计算（目前保存但暂不增量复用）。

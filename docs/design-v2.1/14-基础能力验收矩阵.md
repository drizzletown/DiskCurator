# 14 基础能力专属测试与发布门槛（v2.1 新增）

## 1. 验收通则

基础层 L1 每个“工具”至少通过：接口测试、Windows GUI 手工测试、异常/安全反例、真实数据测试；L2/L3 通过复用入口一致性测试。不以“推荐流程通过”替代基础操作的独立验收。所有结论标注实际版本/OS/文件系统及 PASS/FAIL/NOT RUN/BLOCKED。

## 2. 基础层测试案例

| Gate | 能力 | 通过标准 | 现有证据边界 |
|---|---|---|---|
| BF-01 | 找重复文件 | 改名、大小相同中间字节不同、零字节、不可读、硬链接多组测试，误判为零 | rc6 CTest/CLI 通过部分场景；rc8 L1 人工选择待验收 |
| BF-02 | 手动管理重复文件 | 单项/多项选择保留者；3 独立副本最多隔离 1；同计划跨组全局检查；合法撤销 | rc8 `plan_clean_duplicates` 可复用；新增保留者 UI 与序列测试未验收 |
| BF-03 | 找重复目录 | 同结构同内容、不同根名、空目录差异、同名异内容、读错导致 UNKNOWN | rc6 核心有覆盖；手动目录清退入口未验收 |
| BF-04 | 手动管理重复目录 | 只做逐文件“能否在待清退目录外剩 2 份”判定，不能直接整树删除 | rc8 `plan_retire_directory` 有可复用基础；GUI 未验收 |
| BF-05 | 相似目录发现 | 目录多重集重合、相对路径、单方向包含、不完整扫描、metadata-only伪匹配 | rc6 目录推荐测试通过；新增双向指标未验收 |
| BF-06 | 手工 A/B 目录评估 | 不受推荐阈值影响；A→B、B→A、A/B 选反、同一目录/父子目录拒绝 | `compare_dirs`/`plan_merge_dirs` 可复用；详细 GUI 报告待验收 |
| BF-07 | 指定 A/B 融合 | 复制缺失、同名异内容双存、空目录、重复运行幂等、不覆盖、失败部分状态 | 历史 rc6 Windows CLI 融合 smoke PASS；S2/S3 新策略未验收 |
| BF-08 | 低层复制/移动/改名 | 路径不逃逸、Windows 保留名、目标存在、扫描后变化、撤销及恢复 | rc6 更名/归档 smoke 有覆盖，通用人工复制/移动未验收 |
| BF-09 | 三层安全一致 | L1/L2/L3 对同一条内容的独立副本数一致，用户手选不能绕过保护 | 需新增跨入口集成测试 |
| BF-10 | 真实数据 | 大规模同名、非 ASCII、目录包含、只读/ACL、junction、移动硬盘模拟失联 | 部分 Windows smoke PASS，真实长期运行待验收 |

## 3. 人工操作可用性验收

不需要学习内部术语即可在基础工具中：选择一个目录→找到重复文件→双击查看并标记保留→看到可隔离计数→确认预览；选择两个目录→评估相似性→展开差异→调整策略→复制融合→核对结果；从重复目录结果中右键“查看结构证明/申请安全清退”，得到明确的逐文件阻断原因。整个过程不依赖先运行智能整体迁移。

## 4. 质量红线

严禁把 `相似` 当作 `相同`、把 `两个路径` 当作 `两份独立副本`、把 `两个完全相同目录` 当作 `可以删掉一个目录`、把 `已经复制完` 当作 `源目录可以清退`、把 `隔离` 当作 `空间已释放`。若任何新 UI 引入绕过核心计划执行器的文件删除/移动路径，阻断发布。

# 06 数据安全、双副本不变量与事务设计

## 1. 危险等级和授权

| 等级 | 类别 | 默认动作 | 授权 |
|---|---|---|---|
| R0 | 扫描、分析、比较、推荐、方案编辑与预览 | 只读 | 选根即可 |
| R1 | 非破坏性融合/构建新结构 | 复制，源不动，不覆盖 | 显示计划与影响后二次确认 |
| R2 | 重命名、规则归档 | 源路径变动 | 显示全量旧→新清单、确认、历史记录 |
| R3 | 重复文件隔离和旧目录清退 | 源退出活动目录树 | 每项双副本校验＋独立确认＋恢复机制 |
| R4 | 永久删除/物理空间回收 | **当前不允许** | 如未来开发，需独立设计与专项验收 |

## 2. 双副本不变量：定义与算法约束

对待隔离源文件 `s` 及活动保留者集合 `K`，只有当 `K` 中至少有两个文件 `k1, k2`，且满足所有下述条件时，才能考虑清退：

- `k1`、`k2` 均位于用户所选根目录内、均在本次拟清退的**旧目录之外**（定向旧目录清退），且当前可访问；
- `s ≡bytes k1 ≡bytes k2`：**完整内容逐字节相同**；
- `file_object_id(k1) != file_object_id(k2)`，不能用两个硬链接路径冒充两份；
- 两份均属于活动普通文件，不在软件隔离区/暂存区，也不是计划准备清退的其他文件；
- 执行前复核仍成立，执行过程每一步均维持该不变量；
- 任一项无法证明（例如 ACL、链接、文件变化、文件系统错误）均阻断或留原位。

**普通重复隔离**与**定向旧目录清退**都应保留两份；后者还额外要求两份均在旧目录范围以外。任何“用户同意全清空”不能绕过这些要求。**同一个根目录的两份文件不等于不同硬盘的灾难恢复备份。**

## 3. 事务流水线

```text
用户确认 → 校验根与工作区 → 校验事务状态
         → 校验冻结计划及源/目标前置条件
         → 建立/检查暂存与日志
         → 逐个临时写入/移动
         → 内容校验及持久化请求
         → 不覆盖地提交目标
         → 标记每项及整体状态 → 结果审计
```

对于整体复制，可能存在已经成功提交的若干文件；其他部分失败时状态应是 `PARTIAL`，保留经核验目标，并明确未完成项。不要把“可以重试”宣传成“所有文件事务完全原子”。对于不具备当前保护的物理断电、缓存层行为，需要真实设备试验证据。

## 4. 受保护工作区

`<root>/.DiskCurator-System/owner.txt`、`journal/`、`stage/`、`quarantine/` 是软件控制的操作工作区；扫描应排除工作区。创建和恢复之前应检查 owner 身份标记、目录类型、链接/重解析点和日志状态；异常时拒绝执行新写入，而不是自动清空。

- Windows 新建 owner 标记须规范二进制 LF 写入，并精确兼容旧版有效 CRLF 标记；附带非法内容不得通过。
- 日志必须校验有序状态、源/目标相对路径、stage 唯一性与根内限制，拒绝陌生字段/异常状态；不得让伪造日志移动 `owner.txt` 等内部文件。
- 不应允许用户在 UI 中直接“强制忽略恢复错误”，即使高级工具入口也不允许。
- 回滚/撤销失败应保留证据供人工处理；优先保护唯一可读副本。

## 5. TOCTOU 与计划过期

下列情况使计划过期：源/目标文件增删改、文件内容变化后恢复原时间戳、目录中新增文件、目标被外部进程占用/创建、根路径更换、用户重新编辑规则。不能仅看 `size + mtime` 就判定安全；使用源指纹变化探测、内容再校验、完整来源快照，并在执行每一步时重新核验目标。

## 6. “迁移”和“清退”的严格分离

**阶段 A**：建立新目标目录，按规则复制、复用已存在的完全相同内容、同名不同内容另存；旧目录全部保留。用户可以只做阶段 A，然后结束。

**阶段 B**：在阶段 A 之后重新获取事实和双副本候选。对旧目录中每个文件分别决定“可隔离/必须保留/未验证”，独立生成计划、独立确认。清退不一定能删除旧目录：只要里面存在副本不足或未验证项，旧目录必须继续保留。

## 7. 用户易误解之处的标准文案

| 禁止文案 | 正确文案 |
|---|---|
| “已释放 10 GB” | “已隔离 10 GB 的文件；实际磁盘空间尚未回收” |
| “备份安全：两份” | “在所选目录内找到两份不同文件对象；无法证明位于不同设备” |
| “自动删除旧备份” | “可安全隔离其中满足两份保留条件的文件” |
| “合并完成，旧目录可删” | “新结构已核验，旧目录是否可清退需单独评估” |
| “照片重复” | “视觉相似照片候选，需人工查看” |
| “文件复制事务全部回滚” | “部分目标已成功提交并验证，其余文件未完成，请查看详情” |

## 8. 故障恢复验收层次

单元层：伪造日志、owner 标记、权限、暂存异常、恢复冲突。  
集成层：NTFS 中文路径、长路径、硬链接、junction、外部目标创建、文件占用。  
设备层：低空间、移动盘断开、掉电/进程强杀、重启后核对内容。**设备层未充分通过前不提供灾难恢复强保证。**


## v2.1 人工操作的强制安全复核

- 人工选择隔离文件不得使用“当前有三条路径，所以可隔离一条”的简化结论；对同一文件对象的不同硬链接按一份计算，并要求本计划完成后仍有两个独立活动对象。
- 生成计划时选出的两名保留者不能出现在此计划的其他隔离项中；执行器再次验证两者独立、内容相同且源未变化。违规操作只能拒绝，不能以“用户手动选择”为理由绕过。
- 手动重复目录清退的保留者必须**位于被清退目录之外**，同名目录内容完全相同也不意味着可删除一个目录。
- 相似评估及用户拒绝建议只读；推荐器阈值绝不作为限制人工只读评估的理由。人工融合只能采用非覆盖复制，不能带出目录外写入；实际执行前源/目标快照复核。
- 硬盘故障级备份保障不在单根目录产品的证明能力内；隔离不释放磁盘容量。

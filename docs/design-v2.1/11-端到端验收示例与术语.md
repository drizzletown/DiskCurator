# 11 典型案例与术语（贯穿需求—设计—测试）

## 1. 历史相机备份案例

```text
R/历史照片/
├─ 相机2022/DCIM/
│  ├─ IMG_001.jpg   A
│  ├─ IMG_002.jpg   B
│  └─ IMG_003.jpg   C-旧版
├─ 相机2024/DCIM/
│  ├─ IMG_001.jpg   A（字节一致）
│  ├─ IMG_002.jpg   B（字节一致）
│  ├─ IMG_003.jpg   C-新版（内容不同）
│  └─ IMG_004.jpg   D（新增）
└─ 额外备份/IMG_001.jpg  A（另一普通文件对象）
```

**预期发现**：相机2022 与相机2024 存在真正的内容重合，但 `IMG_003.jpg` 为同名异内容且版本优劣未知。`A` 目前有 3 个路径，只有在不是硬链接、字节确认的条件下才可计为 3 份活动文件对象。

**建议结构示例**：

```text
R/整理结果/
└─ 照片与视频/相机历史资料/DCIM/
   ├─ IMG_001.jpg          A
   ├─ IMG_002.jpg          B
   ├─ IMG_003.jpg          C-某一版
   ├─ IMG_003__来源标记.jpg C-另一版
   └─ IMG_004.jpg          D
```

**映射必须完整**：2022/IMG_001 与 2024/IMG_001 可多对一映射到同一个已字节核验的目标；2022/IMG_003 与 2024/IMG_003 必须映射到不同目标。原目录及 2022 独有内容保留。**上述结构只是可能建议，不代表固定分类规则或自动决定冲突版本。**

### 融合后为何不能直接删旧目录？

原始 `C-旧版` 只有一份，迁移后新结构有第二份；按至少两份独立活动文件对象规则，删掉旧目录中的这份会只剩一份，因此**必须保留**。`A` 是否可隔离一份，需要再次验证当前所有活动副本及文件对象身份，且如果是定向旧目录清退，还要求旧目录以外两份。

## 2. 目录完全相同与内容包含的反例

| 情况 | 目录完全相同？ | 内容包含？ | 结论 |
|---|---|---|---|
| `A/x.jpg` 与 `B/x.jpg` 字节一致，结构也相同 | 是 | 双向包含 | 可标记完全等价目录 |
| `A/x.jpg` 与 `B/y.jpg` 字节一致但相对路径不同 | 否 | 内容集合可能相同 | 不是完全相同目录树 |
| 两目录所有文件一致，但一侧多了空目录 | 否 | 文件内容相同 | 空目录仍是结构差异 |
| 两个同名文件不同字节 | 否 | 不一定 | 必须保留双版本 |
| 两个照片 dHash 距离很小 | 不能推定 | 不能推定 | 只能给出视觉相似候选 |

## 3. 清退案例

某内容 `X` 在 `R/旧备份/` 有一份，在 `R/整理结果/` 一份，在 `R/额外保留/` 一份。这三份若为不同普通文件对象且字节一致，则旧目录这一份**可申请隔离**，因为旧目录外还有两份。若额外保留只是整理结果的硬链接，则必须拒绝。

## 4. 产品术语（用户视角）

| 术语 | 唯一定义 |
|---|---|
| 精确相同文件 | 字节序列完全一致，不以名称/修改时间判断 |
| 完全相同目录 | 相对路径、目录与文件节点（含空目录）及全部文件字节一致 |
| 内容重合 | 两个目录含有部分相同文件内容；不代表目录相同或可互换 |
| 视觉相似照片 | WIC 解码/dHash 得到的待人工核对候选 |
| 融合 | 向目标增量补齐内容，保持源目录不动 |
| 结构建议 | 软件尚未执行的目标目录树和来源映射方案 |
| 迁移（本产品阶段 A） | **非破坏性复制建立新结构**，不是剪切原目录 |
| 复用 | 新目标无需再存同字节内容，但必须有源→目标映射 |
| 冲突版本 | 路径/名称相同而字节不同，保留不同文件 |
| 隔离 | 文件从活动位置移入软件受控隔离区，可以按合法日志撤销 |
| 清退 | 对旧目录选出满足双副本约束的文件进行**隔离**，非永久删除 |
| 活动副本 | 当前可访问的普通文件对象，不属于隔离/暂存区 |
| 独立副本 | 两个不同文件系统文件对象；**不自动意味着两个物理设备** |
| 计划过期 | 计划基于的根、内容、映射或目标前置条件已变化，须重建 |
| 部分成功 | 部分经过核验的文件已提交，其余未完成；不能标记为整体成功 |
| 恢复/撤销 | 根据可信日志安全处理当前事务或上一次允许撤销的变更；并非任何操作都保证可一键撤销 |

## 5. 用户最关心的三个问题

**软件会删除什么？** 默认智能整理阶段 A 不删除源内容；主动清退仅隔离满足双副本约束的文件。  
**新目录靠谱吗？** 完整映射加字节验证使来源可以追溯；未验证、失败与冲突必须明确呈现。  
**真的节省空间了吗？** 当前隔离不会释放实际磁盘空间；软件不得显示虚假的“已释放”指标。

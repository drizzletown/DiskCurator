# DiskCurator 功能体系与总体设计（唯一文档基线 v2.1）

**日期**：2026-11-18  
**状态**：产品/需求/总体设计冻结基线，不是软件正式发行。  
**实际实现参考**：DiskCurator Native **v1.0-rc8** 基础能力源码候选版（Windows 尚待验收）。  
**平台**：Windows 10/11 x64、C++17、原生 Win32 SDK/Common Controls/WIC，无 Qt/MFC。

## 本次重新收敛的结论

一条主线：**看清现状 → 识别关系 → 建议目标 → 审查/编辑 → 构建/验证 → 可选清退**。

三种用户入口：**智能整理（默认） / 主题工具（七种任务） / 基础工具（五组证据视图）**。

五个业务能力域：**盘点、内容关系、智能规划、受控执行、数据保护**。

两个互不替代的阶段：A **复制并验证新的目录结构**；B **重新评估、另行确认旧目录的双副本隔离**。阶段 B 不会因阶段 A 成功而自动触发。

## 基线与实现不得混淆

本次设计调整与 rc8 源码改造同步进行；这不意味着 Windows v1.0 正式版已通过验收。用户证据显示 rc6 Windows MSVC 构建/CTest 7/7/CLI smoke PASS；rc6 GUI smoke 搜索筛选处 FAIL。rc7 提供对应修复代码，但 **Windows GUI 自动化复测尚未提供**。

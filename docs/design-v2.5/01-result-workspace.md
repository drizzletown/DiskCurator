# 01 — 扫描结果工作区

## 需求

- UI-25-01：不创建左侧模式按钮和目录树。窗口主体由范围输入、进度、视角/搜索、操作、结果列表和状态组成。
- UI-25-02：基础/主题/智能操作菜单的打开不切换视角、不重扫、不清空库存。
- UI-25-03：文件行显示位置、大小、SHA以及当前观察的候选副本数；目录行显示累计大小、文件数和目录树候选数。
- UI-25-04：候选与已逐字节核验明确区分。读取不完整的目录不能标为完全相同。
- UI-25-05：列表选择绑定对象路径和来源根；筛选、排序、异步完成不能把旧行号套给新对象。隐藏或失效的选择不能成为错误操作目标。
- UI-25-06：操作作用范围明确区分“所选文件/目录”和“当前扫描范围”。改变扫描输入或磁盘身份后不能对旧库存执行。
- UI-25-07：新预览失败时，不得留下可误执行的旧计划。执行使用已预览并冻结的策略和路径。
- UI-25-08：写操作后不自动重读整个根范围。成功、部分成功、失败或异常均使当前快照过期；旧计划清除，后续分析与写入需显式重扫，历史和只读参考保留。新扫描取消不能重新启用旧计划。

## 功能体系

| 观察视角 | 主要内容 | 可触发动作 |
|---|---|---|
| 文件 | 名称、路径、大小、哈希、候选/精确副本 | 查看位置、选择、隔离预览、重命名、导出 |
| 目录 | 路径、累计大小、文件数、树副本候选 | 选A/B评估和融合、清退、重命名 |
| 副本 | 组、成员、份数、位置、潜在冗余 | 手动选定隔离项、设置K/独立性/核验策略 |
| 关系/比较 | 共有、独有、同名冲突、覆盖率 | 评估指定目录对、生成保留冲突的增量融合计划 |
| 照片 | 相似候选和元数据 | 按需分析、人工查看、归档预览 |
| 目录映射 | 原路径→建议目标、冲突、复制量 | 修改映射、预览、新结构构建、拒绝建议 |
| 计划/历史 | 路径变更、策略、状态 | 确认执行、复查、可支持操作的撤销 |
| 概览/问题 | 根范围、文件容量、未读项 | 选择单盘操作范围、查看错误、重新扫描 |

## 操作类别与选择规则

基础操作：针对选定对象的日常管理、选择/清除、导出、策略设置与撤销。主题操作：重复副本整理、目录融合/清退、归档、照片及目录关系等完整任务。智能操作：生成并编辑推荐、重组映射。

三类均通过相同命令分发和计划执行机制。仅发现内容、打开菜单、切换视角和生成预览不会写入用户资料；修改要经过计划和确认。

多盘观察中选择同一盘的项目后进入该盘操作范围，复用已扫描库存。跨盘混选不能执行本版写操作。单盘视角可以返回多盘结果，返回时说明并清除未执行预览。

大列表使用虚拟 ListView，常用文件/目录结果每次最多构造5000条展示记录；搜索在完整库存上执行，截断提示明确。导出菜单写明“当前显示结果”，避免把显示截取误认为完整导出。搜索有短延迟合并，刷新前先清除可能按旧行号命中的选择。

文件变化后的增量刷新尚未实现。本版采用明确的“结果过期”状态：不会因一次隔离或改名隐式触发数小时全盘读取；用户可以继续参考旧结果和操作历史，并自行选择完整范围或较小目录重新扫描。过期状态跟随当前扫描会话，不能通过切换多盘/单盘视角清除；导出也标明结果过期。

## 双目录任务

A/B可以由目录视角选中两行，也可在对话框中手工指定。评估/融合任务只构造这两个子树的临时分析库存，复用初次完整SHA，按需逐字节确认候选，根内其他文件不参与内容读取。比较可表达包含关系；融合仍要求两个不相交且适合融合的目录。源目录和冲突版本保留。

## 副本策略

清退/隔离从扫描候选生成计划。默认执行时核验实际内容；用户可配置K=0..32、是否按不同文件对象计数、是否再次逐字节核验。候选计划不得修改观察库存中的“已验证”状态。快速模式不应先被强制执行全盘精确核验。K=0授权不持久化，必须每次明确确认。

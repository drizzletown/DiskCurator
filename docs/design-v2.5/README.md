# DiskCurator 需求与设计基线 v2.5

生效日期：2026-11-20。实现版本：Native 1.0.1。

## 当前决定

**扫描结果是唯一工作中心。** 左侧“智能整理、主题工具、基础工具”模式导航及目录浏览树全部取消。基础、主题、智能作为观察结果上的操作类别。它们共用同一份库存、选中对象、预览与历史，不再是三套产品入口。

流程为：指定范围 → 完整扫描与哈希 → 可视化观察 → 选定对象/范围 → 操作预览 → 确认执行。

| [01-result-workspace.md](01-result-workspace.md) | 功能体系、结果与操作关系、选择/筛选身份 |
| [02-scan-performance.md](02-scan-performance.md) | 阶段进度、速度与ETA、I/O和计算性能设计 |
| [03-acceptance.md](03-acceptance.md) | 需求、实现、回归及未验证范围 |

v2.5 替代 v2.4 和更早文档中的左侧三层导航、自动进入精确分析、自动生成建议的行为描述。v2.4 的用户先选磁盘再扫描、v2.2 的完整SHA与可配置副本策略继续有效。历史文档保留用于追溯，不作为矛盾行为的当前实现要求。
